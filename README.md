# Static Class Components (C++)

### Variant 3: Create a class with messages on first object creation and last object deletion

Create a class Alpha in such a way that when the **first object** is created and when the **last object** is destroyed, appropriate messages are displayed on the screen.

**Hint:** Use static components of the class.

# Статические компоненты класса (C++)

### Вариант 3: Создать класс с сообщениями при создании первого объекта и удалении последнего

Создать класс Alfa таким образом, чтобы при создании **первого объекта** и удалении **последнего объекта** этого типа на экран выводились соответствующие сообщения.

**Указание:** Применить статические компоненты класса.
