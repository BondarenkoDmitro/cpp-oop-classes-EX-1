# Static Class Components (C++)

### Variant 3: Create a class with messages on first object creation and last object deletion

Create a class Alpha in such a way that when the **first object** is created and when the **last object** is destroyed, appropriate messages are displayed on the screen.

**Hint:** Use static components of the class.

# Статичні компоненти класу (C++)

### Варіант 3: Створити клас з повідомленнями при створенні першого об'єкта і знищенні останнього

Створити клас Alfa таким чином, щоб при створенні **першого об'єкта** і знищенні **останнього об'єкта** цього типу на екран видавалися відповідні повідомлення.

**Вказівка:** Застосувати статичні компоненти класу.
